## 准备服务器 or 电脑

- 准备 1 台 24 小时保持开机的电脑（最好单独申请专属服务器 避免不兼容等问题）作为打印服务器，目前服务器电脑仅支持 Windows 和 macOS 系统；
- 作为服务器的电脑需要联通外网，且与打印机处于同一局域网内；可以提前用过 cmd Ping 打印机的IP确认

### IPP服务开启（默认就是开启的，除非特意关闭过）

在配置云打印前，需要开启打印机上的【 IPP 服务】（默认开启，可以通过访问打印机的IP，进入打印机后台设置其网络参数），同时 需要开启打印机的 **SNMP** 功能（默认开启），且 **Community** 设置为 **Public（默认）**，具体开启方式请参阅相关打印机说明。 

### 驱动下载

**添加打印机前，请参考打印机厂商说明书或前往官网下载驱动（一定下载对应当前系统版本的打印机驱动进行安装）**

⚠️ 在云打印管理后台搜索添加打印机的过程中，大部分没有搜索到打印机的情况，都是电脑没有安装正确的打印机驱动，可前往对应厂商官网下载后 添加打印机时重新 “从磁盘安装”。

### 添加打印机

- 在电脑上点击 **设置** > **打开打印机和扫描仪** > **添加打印机或扫描仪**。

![图片展示了Windows系统中“打印机和扫描仪”设置界面。左侧为设置菜单，选中“打印机和扫描仪”。右侧显示“添加打印机和扫描仪”页面，有“添加打印机或扫描仪”按钮，下方列出了已添加的打印机，如CloudPrint、Fax、ir-ADV C3525等。该图片与文档中“在服务器or电脑中添加打印机”部分内容相关，直观呈现了添加打印机前的系统界面，为后续添加打印机操作提供参考。](https://feishu.cn/file/KToDbRwzGoi63lxT06Lcvtekn0e)

- **继续搜索到了打印机也建议选择下方的蓝色字体：“打印机不在打印机列表中”**

![图片展示的是在服务器或电脑中添加打印机时，搜索到打印机后出现的提示界面。界面上方有“刷新”按钮，下方以红色框突出显示“我需要的打印机不在列表中”文字。该图片与上下文紧密相关，上下文提到在继续搜索到打印机时，建议选择蓝色字体的“打印机不在打印机列表中”，此图直观呈现了该提示样式，帮助用户明确在打印机不在列表时的操作提示。](https://feishu.cn/file/M9o7bdwAwoKoByxWGDRcF3kunrf)

- 选择**使用 TCP/IP 地址或主机名添加打印机**，点击 **下一步**

![图片展示的是Windows系统中“添加打印机”界面，选择“使用TCP/IP地址或主机名添加打印机”选项。界面上方有“按其他选项查找打印机”提示，下方有五个选项，其中“使用TCP/IP地址或主机名添加打印机”被选中。在主机名或IP地址输入框内，可输入打印机IP地址，右侧有“浏览”按钮。该图片与文档中在服务器或电脑中添加打印机，选择“使用TCP/IP地址或主机名添加打印机”并点击“下一步”的操作步骤对应，是后续输入打印机IP地址等操作的指引。](https://feishu.cn/file/ZIkNbECYcoFdu1x0A6fcucXln2f)

- 在**主机名或 IP 地址**输入框内，输入**打印机 IP 地址**，点击 **下一步，**警惕不要使用系统自定义搜索的打印机驱动（取消勾选），要使用刚才下载的驱动

> **注**：请确保输入的 IP 地址正确有效，IP 地址格式示例：10.93.36.201
> 
> **注**：必须确保打印机为静态IP（动态ip会导致云打印配置失效，不可用）

![图片展示的是Windows系统中添加打印机时的界面。在“键入打印机主机名或IP地址”步骤中，设备类型为“TCP/IP设备”，主机名或IP地址输入框为空，端口名称框也为空。关键信息是“查询打印机并自动选择要使用的打印机驱动程序”选项被红色框突出显示，提示用户取消勾选该选项。此图与文档中在服务器或电脑中添加打印机，选择“使用TCP/IP地址或主机名添加打印机”后，在主机名或IP地址输入框内输入打印机IP地址，警惕不要使用系统自定义搜索的打印机驱动等内容相关，强调了取消勾选该选项的操作。](https://feishu.cn/file/CaeybdCRvo3neyxwplEcIu2Onxf)

![图片展示的是Windows系统中“添加打印机”界面的“安装打印机驱动程序”步骤。左侧有厂商列表，右侧显示打印机型号“HP LaserJet MFP M129-M134 PCLm-S”。下方提示该驱动程序已过数字签名，并有“Windows更新”和“从磁盘安装”两个选项。图片与上下文紧密相关，上下文提到在添加打印机时，若找不到匹配的打印机驱动，可选择“从磁盘安装”，并需选择解压后文件夹内的inf文件（x64），此图直观呈现了该操作界面及选项。](https://feishu.cn/file/WC8Nb9pCyo5hP6xqWWBcbMMqnqd)

## 下载并配置服务器

- 前往 [云打印管理后台](https://cloudprint.feishu.cn/admin/download)，使用**云打印后台管理员帐号**登录，选择合适的版本下载（win 推荐/ mac）

![图片展示的是云打印管理后台界面，标题为“云打印服务器”。界面提示请下载合适版本的客户端并安装到作为服务器的电脑上，分别有Windows版（64位）和macOS版的下载图标。右侧有插画，一人手持平板电脑，另一人手持手机，背景有打印机等元素。下方有“进入管理后台”及“更多操作详情请查看指南”字样。该图与文档中“下载并配置服务器”部分对应，直观呈现了云打印服务器客户端下载及管理后台进入的指引。](https://feishu.cn/file/F5W4b6WoHoIxxpxVo1KcansEnvd)

- 下载后根据**安装指引**安装云打印服务器
- 双击打开下载好的云打印服务器客户端后，浏览器自动打开云打印管理后台，可以进行服务器的创建操作并修改服务器名字；初始服务器名称默认使用 **Agent 01—第一次登录时间**，可自行修改，电脑右下角状态栏内的 Cloud Print Agent 代表正在启动的程序，存在代表正在运行agent（管理后台服务器状态为：在线）

## 问：如何查看云打印服务器的日志？

**答**：进入当前登录用户的目录下 .cloudprint/agent.log，即可找到日志。

Windows 系统：C:\Users\admin\\.cloudprint\agent.log

macOS 系统：/Users/admin/.cloudprint/agent.log

## 问：为什么添加打印机时，未发现新的打印机？

**答**：可能性如下：

1. 目前云打印只支持**通过网络方式添加**的打印机，暂不支持使用 USB 等其他方式添加。
2. 若刚完成添加打印机的操作，请稍等几分钟后刷新页面再试。
3. 没有使用正确的专属该打印机的驱动（计算机自动安装的驱动只能发起作业，但是想要连接云打印需要专属这个型号的最新的 + 适配当前版本的驱动，一般下载**无安装程序版**即可）

   1. 参考上述 [步骤 3.2](https://bytedance.feishu.cn/docx/DVUKdE9XkoNVXax0MatcwNuMn8b#WsutdApqTooSB0xuZMZcUpOJnHb) 重新更换驱动
4. 该打印机的IP地址 、Mac地址、等信息与其他打印机冲突 

PS：ip地址、Mac地址冲突也可能导致打印机可正常添加，但无法使用云打印的情况

1. Windows 服务器上打印机端口设置不正确或冲突。请打开**设备和打印机**，选择无法被发现的打印机并点击右键打开 **属性** > **端口** 检查一下端口名是否为正确的 IP 格式(没有下划线 **\_** )或标准 TCP / IP 端口。如不正确，请切换至正确的端口或删除打印机后重新添加，参考：[部署安装指南](https://bytedance.feishu.cn/docx/DVUKdE9XkoNVXax0MatcwNuMn8b#doxcnkZZKyyaHDmKrA74JhVI4Cd)。查看端口设置是否正确的流程如下：

   1. 在**设备和打印机 / 打印机和扫描仪**中打开打印机属性。打开打印机属性。
