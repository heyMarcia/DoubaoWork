# 企业成员如何使用云打印？

## 一、产品简介

飞书云打印能与飞书云文档、审批、邮箱等联动，提供安全、优质、高效的打印解决方案。企业管理员配置好后，成员即可使用电脑或手机，随时随地轻松发起打印。

管理员请参考：[管理员如何部署云打印？](https://bytedance.larkoffice.com/docx/DVUKdE9XkoNVXax0MatcwNuMn8b)

注意：

> - macOS版客户端没有提供支持搭载Apple Silicon芯片（如M1、M2等）的软件版本，此类mac电脑要先安装Rosetta，才能安装客户端。
> - Rosetta 是苹果公司为搭载 Apple Silicon（M1、M2 等）芯片的 Mac 设计的一个转换层，它允许在这些新芯片上运行为 Intel x86 架构编写的应用程序。这是因为 Apple Silicon 芯片使用的是 ARM 架构，与 Intel 的 x86 架构不兼容。

**安全扫码打印**

用户可直接打开想打印的文件，点击鼠标右键，选择 **打印** 或按 **Ctrl+P / Command+P**，选择打印机  **CloudPrint**，点击 **打印。**

收到云打印 bot 的提醒后，点击 **去打印** ＞ **打印**。

- 点击手机页面右上角的**扫描符号**，前往打印机处，扫描打印机上粘贴的二维码，获取打印材料。
- 或选择要连接的打印机，免扫码开始打印，再前往打印机处直接获取材料。

你还可以在手机上取消打印、删除打印文件、修改部分打印设置。

**答**：可以。如需进行本地打印，请在电脑端飞书搜索【云打印】，进入小程序后点击顶部【客户端】，根据设备下载安装对应客户端。在**一键配置**后，就可以在电脑上直接发起打印，打印时选择**云打印-XXX**（打印机）即可。

## 问：提示**暂不支持打印加密文件**怎么办？

**答**：暂不支持上传加密文件。请先使用电脑本地软件，如 Adobe Acrobat Reader、Office、WPS 等，输入正确的密码打开文件后，再使用云打印的[本地打印方式](https://bytedance.feishu.cn/docx/doxcnqrsMsfFdMQGK3AKRGCvs9f#doxcncQkecIWssoeoU3Grf9F6Xe)进行打印。

## 问：手机上能直接打印飞书云文档吗？

**答**：暂不支持。你可以在电脑上打开飞书云文档，然后使用[本地打印方式](https://bytedance.feishu.cn/docx/doxcnqrsMsfFdMQGK3AKRGCvs9f#doxcncQkecIWssoeoU3Grf9F6Xe)进行打印。

## 问：我上传的文件为什么不见了？待打印的文件为什么在列表里消失了？

**答**：待打印文件在云端的保存时间为 2 小时，2 小时内未到打印机前扫码打印，文件及打印任务会自动在云端删除。

## 问：上传文件时提示文件过大怎么办？

## 问：上传文件时提示上传失败-文件上传失败，请确认文件是否损坏，可尝试另存为新的PDF文件上传。怎么办？

![图片展示的是云打印上传失败的提示界面。上方有“上传失败”标题，下方文字说明发起打印的文件格式或大小不符合要求，仅支持上传JPG、JPEG、PNG、BMP、PDF、DOCX、DOC、PPTX、PPT、XLSX、XLS格式文件，单个文件不超过100MB。该图片与文档中关于上传文件提示失败问题的解答相关，直观呈现了上传失败时的提示内容，帮助用户了解文件格式和大小要求。](https://feishu.cn/file/BhKGbbEf6oPcAUxhcDUclgAunff)

**答**：

1、遇到这个提示通常是因为文件格式损坏、文件过大、文件名称异常等原因。可以尝试[安装云打印客户端](https://bytedance.larkoffice.com/docx/VFtqd4ImkokSFFx8JkvcDaDUnRb#part-JjS0dlRAEojYjjxkcIec5lKSnvd)，使用本地打印方式打印。



2、如果上传文件是PDF格式，文件大小在200MB以内（通过云打印BOT上传文件，大小限制100MB内），通常遇到的问题是PDF格式损坏，检查格式是否损坏的方式

1. **尝试打开 PDF 文件**：  
使用任何标准的 PDF 阅读器（如 Adobe Reader 或者其他免费的 PDF 查看器）尝试打开文件。如果文件能够正常打开，那么它可能没有损坏。
2. **使用 PowerShell**：  
PowerShell 是 Windows 的一个功能强大的命令行工具，它提供了一些可以检查文件属性的命令。虽然它不能直接告诉你 PDF 是否损坏，但你可以获取一些文件信息。

打开 PowerShell 并使用以下命令获取文件的属性：powershell

```PowerShell
Get-ItemProperty "C:\path\to\your\file.pdf"
```

1. **使用第三方工具**：  
有些第三方工具可以检查文件的完整性或尝试修复损坏的 PDF 文件。例如，PDF Repair Tools 或者一些在线服务。

3、如果PDF格式损坏，则需要将PDF修复或转成图片格式再上传。

## 问：上传图片打印时，进度条会卡在 80-99%之间，怎么办？

答：上传进度 80% 到 100% 的过程是文件转码（转成 PDF ）过程，云打印后台会每隔 5s 自动更新。请在该页面耐心等待，页面会加载到 100%，此时上传完成。如等待时间过长，可以把文件转成 PDF 后重新上传。

## 问： **云打印**支持扫描吗？

**答**：暂不支持。如需对文件进行扫描或扫描打印，可以直接使用具有扫描功能的打印机操作（按照打印机面板上的提示操作即可）。

## 问：**云打印**支持哪些类型的纸张？

**答**：目前支持的纸张类型有 A4、A3、A5、Letter、Ledger、Legal。打印过程中，请参考打印机具体可支持的纸张类型，从以上类型中选择。

## 问： **云打印**支持哪些类型的文件？

**答**：目前上传文件支持的格式为 JPEG、PNG、BMP、PDF、DOCX、DOC、PPTX、PPT、XLSX、XLS，单个文件需小于 100 MB。本地打印暂时没有限制。

## 问： **云打印**是否可以重新打印文件？

**答**：暂不支持。为了更加有效地保障信息安全，打印完成后文件会自动在云端服务器删除。如需重复打印当前文件，请重新发起打印。云打印对发起打印的文件进行加密传输与存储，**即扫即打印即删除，保护隐私安全。**

## 问：macOS客户端安装时提示需要先安装Rosetta怎么办？

![图片展示的是macOS系统中安装云打印MacOS版客户端时，若要打开“App”需先安装Rosetta的提示窗口。窗口上方有齿轮图标，中间文字说明安装Rosetta的必要性，下方有“以后”和“安装”两个按钮。该图片与上下文紧密相关，上下文解释了Rosetta在macOS系统中作为翻译层的作用，以及云打印MacOS版客户端目前未适配Apple Silicon芯片，安装时会提示需先安装Rosetta。](https://feishu.cn/file/FIz1bmtQmoR1eYxPSuWctPbInCr)

答：在macOS系统中，Rosetta是一个翻译层，它允许在搭载Apple Silicon芯片（如M1、M2等）的Mac电脑上运行原本为Intel处理器编写的应用程序。由于这些芯片使用的是ARM架构，而许多现有的macOS应用程序是为Intel的x86架构设计的，因此需要Rosetta来转换这些应用程序，使其能够在新的硬件上运行。

目前云打印MacOS版客户端暂未适配Apple Silicon芯片，在安装时会提示需要先安装Rosetta。您可以按照其提示进行安装，再安装云打印客户端或使用小程序进行打印



关于Rosetta安装方式

1. 使用MDM策略：对于已经绑定了MDM（移动设备管理）的新电脑，您可以在MDM策略中设置自动运行Rosetta的安装命令，这样用户就不需要手动安装了。
2. 手动安装：对于没有MDM的老电脑，您需要手动执行上述命令来安装Rosetta。

## 问：为什么在打印机后台日志中，飞书打印机的使用人会出现unknown？

文件名称、上传人这些数据是拿不到的，设计之初为了规避隐私风险，这些敏感数据在打印完成后，云端就会在2小时内直接删除掉。如果还能看到，是2小时内未删除的数据，2小时后云端就会删除的。

- 重启电脑

错误码1802

清理 Windows 打印机缓存：

- 步骤一：按 win + R 键，在弹出的窗口中输入 services.msc，点击【确定】
- 步骤二：在列表中找到 print spooler。右键【停止】该服务。

> 注意：正在打印的文件会失败。停止服务期间，该电脑暂时无法打印。

- 步骤三：进入C:\Windows\System32\spool\PRINTERS
- 步骤四：全选里面的所有文件，将这个目录下的所有文件**删除。**建议删除前先进行备份
- 步骤五：在 services 里面，右键 printer spooler **启动**该服务

# 企业管理员如何使用云打印管理后台？

## 一、产品简介

飞书云打印为企业提供安全、优质、高效的打印解决方案。云打印能与飞书云文档、审批、邮箱等联动，后台运维管理清晰、员工使用简单便捷，帮助企业随时随地轻松发起打印。

管理员可在云打印管理后台管理办公点及打印机设备、设置打印机使用权限、配置打印功能等。

## 二、操作流程

### 管理办公点及打印机

#### **新增办公点**

进入 [**云打印管理后台**](https://cloudprint.feishu.cn/admin)。初始化时，打印机会默认关联在 **办公点列表** > **默认办公点** 上。默认办公点可以编辑但不可删除。管理员也可以点击 **新增办公点**。

![图片展示的是云打印管理后台的办公点列表页面。左侧导航栏中“办公点列表”被选中。页面上方有“办公点列表”标题，下方显示办公点名称及更新时间，如“广州办公点”“默认办公点/Default”，并有“编辑”“删除”操作选项。页面右上角有“+ 新增办公点”按钮，右下角有分页和每页显示条数的设置选项。该图片与上下文介绍的新增办公点操作流程相关，直观呈现了办公点列表页面及新增办公点按钮位置。](https://feishu.cn/file/boxcncRUaTItGa8TJyoXor1Em9g)

#### **删除办公点**

如删除时该办公点名下有打印机，需要先在系统中将打印机转移到其他办公点，再执行删除。

#### **编辑打印机信息**

点击 **打印机列表** > **操作** > **更多**，可在 **详情** 或 **编辑** 中调整打印机信息以及打印机匹配的办公点。

**注**：一台打印机只能匹配一个办公点。如切换打印机匹配的办公点，则办公点管理员信息也会同步切换。

### 统计分析

- **纸张数据分析**

# 云打印服务器相关问题 

## 问：目前支持哪些操作系统？哪个操作系统版本更适合我？

**答**：目前仅支持 Windows 和 macOS 系统。Windows 系统的在兼容性上更优，macOS 系统在稳定性上更好。各操作系统的最低版本要求及推荐如下：

- Windows 需要 64 位或以上操作系统版本，推荐 Windows Server 2012 R2 或以上
- macOS 需要 10.13 或以上操作系统版本

**注**：由于厂商驱动程序兼容性问题，如果你使用的是佳能 Canon、震旦 Aurora、东芝 Toshiba 的打印机，建议使用 Windows 操作系统作为云打印的服务器

## 问：云打印服务器能否使用 Linux 系统？

**答**：目前仅支持 Windows 和 macOS 系统，其他如 Linux、Unix 操作系统暂不支持。

## 问：云打印服务器的windows 版本是否有要求或者推荐？

**答**：Windows Server 2019（已经反馈可用） 以及 Windows Server 2012（推荐版本）

## 问：云打印服务器的出现问题，需要更新根证书（例如：出现长期超时状态）

**答**：[下载根证书链接](https://www.catalog.update.microsoft.com/search.aspx?q=kb4474419) 或 其他官方链接

## 问：服务器有没有什么硬件上的要求？

**答**：硬件没有具体要求，可参考对应操作系统的推荐配置。

## 问：云打印服务器能否使用虚拟机？

**答**：云打印服务器可以运行在虚拟机中，使用虚拟机时请分配足够的资源，以保障操作系统运行流畅。具体的配置要求，请参考对应操作系统的推荐配置。

## 问：可以直接从云打印采买硬件，用来部署服务器吗？

**答**：暂时不支持购买。可以考虑使用普通办公电脑作为云打印服务器。

## 问： macOS  和 Windows 服务器能并行吗？备用机怎么配置？

**答**：企业可以同时部署  macOS  和 Windows 服务器。当同一台打印机同时连接了  macOS  和 Windows 云打印服务器时，每次打印将随机选择一台可用的服务器。

## 问：为**什么 Windows 版本的服务器，在客户端安装后无法打开？**

**答**：目前 Windows 版本的服务器仅支持 Windows 7 及 64 位以上的 Windows 版本。若安装失败或无法使用，请确认电脑系统是否符合标准。

## 问：为什么服务器处于离线状态？

**答**：

- 请确认是否是网络问题或服务器客户端不在运行状态，请尽量保证安装服务器的电脑为运行状态，关闭电脑自动休眠，且网络畅通；对于 macOS 电脑，请开启自动登录。
- 请更新系统根证书

## 问：**在安装服务器客户端的电脑上打印出错，导致打印机无法使用怎么办？**

**答**：部分 Windows 或 macOS 系统更新，可能会导致服务器偶发报错。此时请尝试在电脑中删除当前的打印任务，并重启电脑。

## 问：是否可以有办法 通过什么方式确认 agent 的可用状态吗

**答：**可以用 8888端口来判断服务是否存活，Agent 启动后，会开启 8888 端口的 HTTP 服务

- 如果 Agent 挂了，8888 端口直接不通
- 如果 Agent 正常运行，8888 端口会返回 HTTP Code 404

## 问：如何查看云打印服务器的日志？

## 问：mac端agent的兼容性问题（未来可能会发生）

- 现象：mac端agent会出现不适配打印机参数的现象（例如：无法在富士施乐上双面打印、无法在佳能上双面短边打印、无法在震旦上设置纸张大小等等）
- 原因：mac底层会将打印参数封装成一个map，这个map里面的参数打印机驱动可能不兼容。（例如，agent认为双面打印为"Duplex:DuplexTumble"，但佳能的双面打印参数为"CNDuplex:Duplex"）
- 解法：在cups/translate-ticket.go这个文件中有翻译参数的功能。修改里面的代码，使agent能传出适应打印机驱动的参数
- 其他：查某个打印机驱动的参数的方法：/Library/Printers/PPDs/Contents/Resources中有描述驱动参数的内容，查里面的文件即可

## 问：windows的agent偶尔会打印机集体掉线怎么办？

- 现象：agent上关联的打印机偶尔集体掉线。（此agent在香港，打印机在日本、欧洲等地）
- 原因：大概是网络抖动。现在agent判断打印机是否掉线的方法是：

  - 与打印端口建立连接：1秒超时，重试3次
  - 发送snmp请求：2秒超时，重试3次
- 解法：放宽超时
- 其他：这个掉线只是偶尔会发生，大部分时间打印机是稳定的。可以观察一段时间再做决定解不解决。

## 问：为什么打印机启用后会自动停用？

**答**：可能因为电脑有重复添加的打印机，需要删除打印机驱动，重新添加打印机。

Windows：**打印机与扫描仪** > **打印服务器属性** > **驱动程序** > **删除对应打印机驱动。**

macOS：直接删除重复的打印机即可。

## 问：为什么打印机状态为离线？

可能有以下原因：

1. 打印机连接的服务器离线了（设备原因）
2. 云打印的服务器客户端 (Cloud Print Agent) 尚未运行， [判断Agent是否存活的方法](https://bytedance.larkoffice.com/docx/doxcnqrsMsfFdMQGK3AKRGCvs9f#part-I9WDdAXJboW6N6xDsmXcWqapnze)
3. 打印机与服务器客户端不在同一网段或打印机没有联网：请检查服务器客户端与打印机的网络，在云打印服务器上打印机状态是否为正常可用。
4. 打印机处于暂停或停用状态：请在服务器上检查打印机状态是否为暂停或停用。如果是，请根据操作系统提示，恢复打印机到可用状态。
5. 打印机所关联的所有服务器处于离线状态：

- 请确认是否是网络问题或服务器客户端不在运行状态，尽量保证安装服务器的电脑为运行状态，关闭电脑自动休眠，且网络畅通
- 请更新系统根证书
- 对于 macOS 电脑，请设置 macOS 系统为永不眠休，并开启自动登录
- 我们仍然推荐用专用的服务器部署云打印而不是个人PC

## 问：发起打印后一直是打印中，不能成功打印？

**答**：请在云打印服务器的电脑上观察打印机状态、打印队列是否有异常。并尝试在云打印服务器的电脑上直接打印，看能否正常打印。如果也不能正常打印，可能是打印机安装配置有问题。请在云打印服务器上删除相关打印机，参考 **问：Windows 系统如何添加打印机？**或者  **macOS  系统如何添加打印机？**，在服务器上重新安装打印机。

## 问：云打印后台提示打印机缺墨，但墨盒内实际还有墨，怎么办？

答：

1、请先至云打印后台的-统计分析-[故障分析](https://bytedance.larkoffice.com/docx/doxcnqrsMsfFdMQGK3AKRGCvs9f#part-Kdimd7b2AoZ1FKxgvzGcPkqKngf)-告警规则检查缺墨告警的阈值。建议缺墨阈值调整到1% 或 2%

2、针对缺墨的打印机更换墨盒或添加墨粉消除缺墨告警。

3、若仍有缺墨提示，建议先关掉云打印后台的缺墨告警，以打印机墨盒用量为主。



## 问：同一时间多台打印机出现内容为空的打印任务，导致打印机卡住，怎么办？

答：

1、遇到此问题，请先通过防火墙的访问历史，查询访问打印机的IP，并判断是否来自安全扫描任务

2、明确问题根因后，请重启打印机，或登录云打印后台取消打印任务

3、将打印机网段下的端口梳理并提供给安全团队，在安全扫描时避免对该端口进行扫描。

# 安全及私有化相关问题

## 问：云打印是如何保证文件安全的？

**答**：

- 文件从上传到打印，通讯全程进行 SSL/TLS 加密，安全抵达企业打印机。
- 待打印的文件会进行 AES-128 位加密存储，打完或超过 2 小时未打印，文件会从服务器上自动删除。
- 打印机代理单向访问互联网，企业内网安全不受影响。

## 问：文件会传输到公网吗？文件的加密密钥可以由企业自主控制吗？

**答**：目前云打印暂无私有化方案，暂不支持第三方密钥。文件通过安全加密通道传输到公网，并加密存储。

## 问：打印文件的时候，如何确保不同成员的文件不会交织打印，导致文件被错拿？

**答**：在 **安全扫码** 模式下，一台打印机在同一时间只能处理一名成员的打印文件。此时如果其他成员尝试扫码打印，小程序会提示用户打印机正在被使用，不能打印。只有当上一成员完成打印后，其他成员才允许发起打印。

## 问：如出现安全拦截情况，配置 Windows 安全放行策略时，需要将云打印客户端的哪些进程加入白名单？ 

**答**：可在 Windows 安全中心、防火墙或者杀毒软件里将以下文件配置到白名单中。

CefSharp.BrowserSubprocess.exe

OneClickConfiguration.exe

OneClickConfigureUI.exe

web.exe

CloudPrint.exe

CloudPrintWatcher.exe

UIInvoker.exe

## 问：两个飞书团队可以配置同一台打印机吗？

可以，但需要分别在各自团队的飞书云打印管理后台中添加打印机，并配置不同的打印二维码。
