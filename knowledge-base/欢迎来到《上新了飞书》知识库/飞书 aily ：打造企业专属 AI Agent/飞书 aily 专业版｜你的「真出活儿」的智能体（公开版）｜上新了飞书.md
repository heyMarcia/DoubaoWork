- **新的飞书深度集成能力（Feishu-use）功能和知识问答的区别是？**

知识问答是将飞书内的各类信息先做好索引，在需要的时候随时取用。 Feishu use 是给 agent 读写飞书各类信息的权限，Agent 可根据任务的需求自行调用相关能力检索相关信息，信息更全面，但耗时更长，两者结合、按需调用，效果更好。
