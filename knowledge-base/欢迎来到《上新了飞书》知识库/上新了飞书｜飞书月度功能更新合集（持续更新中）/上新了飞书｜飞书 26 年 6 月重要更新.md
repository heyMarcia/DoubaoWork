# 🤖 全文精华速览

<callout emoji="💬">
文档核心内容
本文汇总了 2026 年 6 月飞书全产品线的重要更新，主题围绕 **AI 深度融入工作流** 展开，覆盖多维表格、CLI、aily 智能伙伴、妙搭、项目管理、People 等产品线。
1. **飞书多维表格**：全新 AI 搭建能力

   - **全新智能体**（即将全量）：表格变身「AI 同事」，群里 @Ta 即可问数据、查异常、看风险
   - **AI 数据分析**：一句话获得专业分析与洞察，斩获 TableBench、FDABench、SpreadsheetBench 三项世界第一
   - **AI 搭建页面/系统**（内测中）：一句话描述即可自动生成自定义页面或完整系统
   - **仪表盘支持 AI 总结**：智能分析图表数据
   - **问卷支持 AI 润色、AI 语音录入**
   - **AI 侧边栏支持模式选择和插件查找**
   - **应用模式支持自动化截图推送**
2. **飞书 CLI：**从「你说一句做一件」到「事件驱动自动化」

   - **会议 & 妙记**：一步拿全纪要/逐字稿/待办；批量修改认错人/听错词
   - **内容创作**：一句话画飞书画板（架构图/流程图）；幻灯片一键截图；表格整本导出导入
   - **自动化（核心亮点）**：支持事件监听常驻——会议结束自动收尾、任务变更自动跟进、卡片按钮触发流程、画板变更自动感知
   - **应用开发：**扔个链接给 Agent，它就把妙搭应用接着做完
   - **其他**：交互卡片格式补齐、Feed 会话置顶、妙搭应用自带数据库/可观测性
3. **飞书 aily 智能伙伴**

   - **模型更新**：新增 Kimi-K2.6、MiniMax-M3、GLM-5.2
   - **浏览器插件**（专业版）：aily 可真正操作浏览器——搜索、点击、填表、翻页、下载、提交，目标驱动自主规划，全程可见可接管
   - **网络出口管控**：支持管理员精确管控智能体可访问的外部网络，拦截高风险行为，确保智能体始终在企业安全边界内运行。
   - **邀请有礼活动**：每邀请 1 位新用户激活智能伙伴，双方各获 20 次免费体验，累计最高 200 次
4. **飞书妙搭**

   - **自定义域名**（灰度中）：支持将应用地址换为企业自有域名
   - **多智能体协作**：妙搭助手统筹分配子任务给专业助手并行处理，从单助手进化为团队协作
   - **开放 API（OpenAPI）**：自然语言创建接口、可视化调试与文档、API Key 鉴权管理
   - **妙搭 × 飞书 CLI：**妙搭低代码「搭」出应用，支持多智能体编排与 OpenAPI 开放；lark-cli 让 Agent 直接接管改代码、查数据、发布、配置全链路，搭完即可交棒
5. **飞书项目**

   - **计划表 MCP 工具开放**：AI Agent 直接操作计划表，一句话完成排期创建/编辑/查询
   - **飞书项目开发工具 CLI**：面向 AI Agent 的开发工具，在 AI IDE 中用自然语言完成插件/应用开发全流程
   - **计划表协同升级**：父子节点独立发布、变更审批左右分栏对比视图、二次编辑能力
   - **数据分析**：图表预计算模式（支持 100 万条数据）、度量公式新增动态时间函数
   - **轻应用**：新增阶段图组件、附件管理组件
6. **飞书 People**

   - **自定义连接器新增**：考勤组/班次/排班数据源、假期发放记录数据源，数据同步至多维表格统一管理
7. **伙伴 AI 方案上新**（首批 AI 包接入）
8. **直击先进**

   - 第 139 期：康师傅饮品 AI 提效实践（AI 识图巡检、AI 竞品情报、AI 制度管理）
   - 第 141 期：锦江酒店 AI 提效实践（无代码做 AI 工具、从单点到批量孵化）

# 飞书 CLI 更新

<grid><column width-ratio="0.500000"><p>这个月，飞书 CLI 学会了「自己接着干」——终端里的飞书，从「你说一句它做一件」，正在长出「你订好规则，它自动接着干」的本事。6 月连发 17 个版本（v1.0.45 → v1.0.61），挑几件你能立刻用上的说说。</p></column><column width-ratio="0.500000"><whiteboard token="GOVVwR43ihcUNgbTBN9cFviAnch"></whiteboard></column></grid>

## 会议 & 妙记：开完会，收尾更省事

会议记录散落在纪要、妙记好几处，整理还得手动。现在一句话，纪要、逐字稿、待办一起给你，认错的地方也能批量修。

<callout emoji="🤖">
**📝 一场会，一步拿全纪要和逐字稿** — 不用在纪要、妙记几个入口来回翻，一次全给你，还能顺手整理成待办。
> 💬 试试说：「把刚开完的周会逐字稿整理成待办清单，分给对应的人」
**✂️ 妙记认错人、听错词，批量改** — 发言人整段重绑到正确的人，识别错的词一键替换，纪要立刻干净可用。
> 💬 试试说：「把这份妙记里认错的发言人换成对的，再把『飞书 CIL』都改成『飞书 CLI』」
</callout>

## 内容创作：你说一句，它产图产表

画板、幻灯片、表格，过去都得人肉拖拽半天。现在把想法描述清楚交给它，图和表直接生出来。

<callout emoji="🧩"><p><b>🎨 一句话，把图画进飞书画板</b> — 架构图、流程图，描述清楚它直接画好；现有画板也能一键导出成图。<cite doc-id="Xjkhdh1S4ocnwtxUyFgckKsFnNf" file-type="docx" title="飞书 CLI 画板能力精选演示" type="doc"></cite></p><blockquote><p>💬 试试说：「把这套系统架构用飞书画板画出来，模块分层清楚点」</p></blockquote><p><b>📸 幻灯片一键截图</b> — 某一页存成本地图片，直接贴进汇报、周报、宣传稿，不用手动截屏。</p><blockquote><p>💬 试试说：「把这份幻灯片第 3 页导出成图片给我」</p></blockquote><p><b>📊 表格整本搬，结构数据都在</b> — 多维表格、电子表格连结构带数据导出导入，换个空间照样用。</p><blockquote><p>💬 试试说：「把这个多维表格连结构带数据导出，我要迁到另一个空间」</p></blockquote></callout>

## 自动化（进阶）：事件来了，它自己响应

<callout emoji="🚀">
这是这个月最值得关注的方向：CLI 不再是「跑完就退」，而是能一直盯着——消息、任务、画板、卡片按钮，谁一动，它自动接着办。它开始像个能常驻的助手了。
**🎬 会一结束，自动收尾** — 监听「会议结束」，一散会就自动整理纪要、建待办、发进项目群。
**✅ 任务一变，自动跟进** — 谁更新了任务，自动同步看板、@ 负责人、触发下一步。
**🔘 卡片按钮点一下，流程自动跑** — 卡片上的按钮、表单被操作，自动建单、通知、更新卡片。
**🖍️ 画板一改就知道** — 画板一有更新就感知，适合协作监控和自动同步。
> 💡 这类自动化需要先做一次配置（让 CLI 常驻监听对应事件），不是说一句就永久生效。想看具体怎么搭，可找产品要一段 demo。
</callout>

## 应用开发：扔个链接给 Agent，它就把妙搭应用接着做完

过去搭个妙搭应用，环境、数据库、发布得自己一项项抠。现在把应用链接丢给 Agent（Codex、Claude Code、Cursor、Gemini CLI 都行），改代码、查数据、发布上线、排障，一条龙接手。<cite doc-id="Won0dWBYvopfH3xhDflc4xuznef" file-type="docx" title="妙搭 × 飞书 CLI：把应用交给 Agent 创建、迭代与运营 ｜ Spark × Lark CLI: Build, Evolve, and Operate Apps with Agents" type="doc"></cite>

<callout emoji="💡">
**🔗 一句话把应用交给 Agent，改完直接发** — 不用记命令，把妙搭应用链接给它，验证完自动发布，顺手把最新线上链接返回来。
> 💬 试试说：「这是我的妙搭应用：`<app-url>`。请完成修改，验证后发布，并返回本轮最新线上链接。」
**🧰 三种开发模式随需切** — 已有静态页面就走 HTML 托管，小修小改用云端会话，复杂前后端联调拉到本地开发，怎么顺手怎么来。
> 💬 试试说：「这里有个静态目录 `./dist`，请用妙搭发布成可访问链接。」
**🗄️ 应用自带数据库、文件、可观测** — 不用另接一堆基础设施：只读查表结构、上传素材拿签名链接、看应用日志和调用链定位线上报错。

## 妙搭 × 飞书 CLI：搭应用和接应用，一气呵成

<cite doc-id="Won0dWBYvopfH3xhDflc4xuznef" file-type="docx" title="妙搭 × 飞书 CLI：把应用交给 Agent 创建、迭代与运营 ｜ Spark × Lark CLI: Build, Evolve, and Operate Apps with Agents" type="doc"></cite>

**一句话简介：**妙搭负责低代码「搭」——建应用、组多智能体、开 OpenAPI；lark-cli 负责命令行「接」——让 Codex、Claude Code 等 Agent 直接接手妙搭应用，改代码、查数据、发布、设访问范围一条龙跑完。

过去搭完一个妙搭应用，发布、配域名、对接外部系统还得在控制台里点点点；现在妙搭产出的应用，天然就是 lark-cli 能操作的对象——Agent 一句话就能接管「修改 → 验证 → 发布 → 放开访问」整条链路，妙搭搭得快，Agent 接得也快。

1. **搭**：在妙搭里用自然语言搭出应用雏形。
2. **接**：把应用链接交给 Agent（Codex / Claude Code / Cursor / Gemini CLI），它继续改代码、调样式、跑本地验证。
3. **发**：验证完，Agent 直接发布，返回最新线上链接。
4. **管**：一句话放开访问范围、配自有域名、新建 OpenAPI Key 对接外部——全程不用回控制台。
