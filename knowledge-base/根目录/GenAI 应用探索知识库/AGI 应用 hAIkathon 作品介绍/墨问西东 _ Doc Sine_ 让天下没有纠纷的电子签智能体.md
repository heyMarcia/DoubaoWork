- **作品名及定位：**

Doc Sine: 让天下没有纠纷的电子签智能体

- **作品描述：**

Doc Sine 致力于简化和自动化合同流程，通过智能电子签名和合同管理平台，提供AI驱动的合同起草、个性化模板和条款检查功能，集成Lark、Zapier等，帮助用户快速、安全地完成合同签署和管理，提升企业效率和合规性。

- **团队介绍：**

杭州墨熵专注于大语言模型应用。我们三年内的战略目标是致力于通过创新AI产品，帮助全球创作者开拓新盈利模式。创始团队包括伯克利博士生、ACM算法奖获得者、连续创业者和00后年轻才俊。我们始终活跃于开源社区，多次为Vercel AI、Replicate等知名项目贡献力量，推动技术进步与共享。
