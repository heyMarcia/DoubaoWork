## Copilot 查询方式

1. 从 Decision Card 取唯一主假设（客户问题）
2. 在「飞书方案素材地图 §二 产品能力地图」匹配模块→场景→痛点
3. 在「§三 行业解决方案地图」匹配同行业典型痛点与方案方向
4. 在「§五 客户案例索引」查找可引用的同行业/同场景标杆
5. 按「§六 方案适配判断指南」输出适配等级

## 硬性约束

- 方案适配 ≠ 问题价值成立：门②通过不替代门①（客户价值认领 ≥ L2）
- 不编造方案效果：引用标杆案例时只说「某客户在某场景下用飞书达到了某结果」，不说「你也会达到」
- AI 探索作品（hAIkathon）标注「探索阶段，非成熟商业方案」
