# 全新能力拆解

## 从"工具"到"同事"

不再是一个孤立的入口，而是以 Agent 形态常驻飞书，人格化、可配置、有记忆——真正成为你在飞书里的智能同事。

## 从"碎片响应"到"持续进化"

系统每日自动汇总工作记忆并抽取核心要点；用户可主动为 Agent 划重点、安装自定义 Skill；社区技能库根据工作偏好智能推荐——你的 AI 助理每天都在变得更懂你。

## 从"被动等待"到"主动干活"

具备飞书内事件感知能力，实时监听IM消息、文档等事件；定时任务、业务事件触发、主动服务管理，智能伙伴在你专注工作时，已经在后台帮你处理好了。



# 常见问题（FAQ）及其他信息

## **Q1：如何找到我的飞书 aily 智能伙伴？**  

在飞书联系人中搜索「aily」，点击「认领专属智能伙伴」开始激活。由于当前名额火热，前期将采用排队机制，系统会按顺序自动推送认领卡片——点击认领后，专属助手即自动完成创建与授权，全程无需任何复杂配置。 

 

## **Q2: 我可以在哪里唤起我的智能伙伴？**  

你可以直接搜索个人助手的名字以及在对话侧边栏唤起。 

 

## **Q3：我的数据安全吗？**  

AI 操作权限与本人账号权限完全一致，支持 Skill 安全扫描、敏感操作人工确认，全程可审计追溯。 



## **Q4：智能伙伴预约页面显示「无权限」「当前企业暂未开启该功能」，该如何解决？**

1. 请联系企业管理员，确认是否为您开通了智能伙伴使用权限；
2. 若权限已开通，请确认企业是否在智能伙伴的服务准入名单内，可联系<cite type="user" user-id="ou_724f3d58bb5f4e530df57f6274e4e707" user-name="崔丽蓉"></cite>协助核查。
