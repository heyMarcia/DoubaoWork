# 飞书即时消息 10 月更新

## 💬 支持自定义iPad导航栏

你可以自定义 iPad 端导航栏，更便捷地打开你需要的页面及应用：

- **直接浏览**：你可在 iPad 端内直接打开文档、多维表格等页面及应用目录中的应用，无需切换为独立窗口。
- **自主设置**：你可以按照自己的使用习惯，拖拽调整导航栏中的应用顺序，固定常用的应用，收起不常用的应用。
- **切换视图**：你还可以通过 **收起** 或 **展开导航栏** 自由切换导航栏视图。

> **注**：该功能仅支持在 iPad 设备使用，Android 平板设备不支持使用此功能。

## 🛠 云表格：单元格插入的图片可自适应大小

你可以在表格中插入单元格图片和浮动图片。

**单元格图片：**图片将被嵌入单元格，图片大小随单元格大小变化。每个单元格内只能插入一张图片，并不能再输入文字。

**浮动图片：**图片将悬浮在表格单元格上方，图片大小也不随单元格大小而变化。

# 飞书工作台 10 月更新

## 📩 支持向动态用户组成员展示管理员推荐应用

工作台管理员设置推荐应用的可见部门或员工时，支持选择动态用户组。

动态用户组是指，用户组的成员是动态变化的。系统会根据特定的筛选条件自动调整用户组的成员。例如，校招实习生用户组中，新的校招实习生会自动加入该用户组，转正后则自动脱离该用户组。

> 配置路径：**飞书管理后台 > 工作台 > 工作台设置 > 管理员推荐 > +添加推荐规则 > 设置部门或员工。**

# 飞书开放平台 10 月更新

## 📽 飞书会议室：2 个接口新增字段

- [**查询会议室预定数据**](https://open.feishu.cn/document/server-docs/vc-v1/meeting-room-data/get-4?appId=cli_a2524c489eb0900e) API 接口返回中增加 reserver_user_id 字段，可通过该字段查询到会议室预定者 id，解决租户内同名用户无法确定预定者的问题
- [**查询参会人明细**](https://open.feishu.cn/document/server-docs/vc-v1/meeting-room-data/get-2?appId=cli_a2524c489eb0900e) API 接口返回中，如果是会议室，则增加 meeting_room_id 字段，解决无法判断会议参会人是否为会议室的问题



## 🙋‍♂️ 飞书人事：新增多个 API，批量查询更方便

- 新增 [**获取任职信息列表**](https://open.feishu.cn/document/uAjLw4CM/ukTMukTMukTM/corehr-v2/employees-job_data/query?appId=cli_a2524c489eb0900e&from=from_parent_sheet)**、**[**批量查询员工任职信息**](https://open.feishu.cn/document/uAjLw4CM/ukTMukTMukTM/corehr-v2/employees-job_data/batch_get?appId=cli_a2524c489eb0900e&from=from_parent_sheet) API，支持批量查询员工的任职记录。
- 新增飞书人事查询 HRBP 的 3 个 API，支持业务系统[**查询员工 HRBP / 属地 BP**](https://open.feishu.cn/document/uAjLw4CM/ukTMukTMukTM/corehr-v2/employees-bp/batch_get)、[**查询部门 HRBP**](https://open.feishu.cn/document/uAjLw4CM/ukTMukTMukTM/corehr-v2/bp/get_by_department)、[**获取 HRBP 列表**](https://open.feishu.cn/document/uAjLw4CM/ukTMukTMukTM/corehr-v2/bp/list)，方便业务系统同步人员权限
- 新增 [**待入职人员信息变更事件**](https://open.feishu.cn/document/uAjLw4CM/ukTMukTMukTM/reference/corehr-v1/pre_hire/events/updated) API，实现待入职人员信息更新后，触发此事件，便于下游系统接收事件后，做后续数据处理。
