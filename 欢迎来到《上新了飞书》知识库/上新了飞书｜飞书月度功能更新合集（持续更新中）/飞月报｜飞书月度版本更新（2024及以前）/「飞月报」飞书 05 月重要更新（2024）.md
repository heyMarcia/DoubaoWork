# 飞书云文档 05 月更新

## 🖼 **幻灯片可隐藏**

你可以设置隐藏幻灯片中的部分页面，在演示模式中，隐藏的幻灯片页面将默认不展示，且无法下载为 PDF。幻灯片演示更灵活，满足更多场景需求。

# 飞书审批 05 月更新

## 💡明细表格支持批量复制粘贴

- 从其他地方（例如：表格、多维表格等）复制所需填入的内容。
- 在申请中，点击所需填入的首格位置，再点击鼠标右键，选择 **粘贴**，即可完成粘贴（你也可以使用快捷键完成粘贴：**Ctrl + V**（Windows）、**Command** **+** **V**（Mac））。

**注**：支持按行、按列、多行多列粘贴。

## ⚙️日期控件支持提交范围设置

管理员有权在表单中设定日期提交的范围。例如，如果希望采购日期仅限于未来一个月，便可进行相应设置。这样用户在提交审批时，只能选择未来一个月内的日期，其余时间则无法选择。

![图片展示了飞书表单中日期控件的设置界面。左侧为控件选择栏，有文本、数字、日期等多种控件类型。右侧是“采购专员使用”表单的表单设计界面，日期控件被选中。在日期控件设置区域，有“提交人可选日期”下拉框，其中“所有日期”被选中，下方还有“本周”“本月”“最近7天”等日期范围选项。该图片与上下文介绍的日期控件支持提交范围设置的内容相关，直观呈现了设置界面及可选日期范围。](https://feishu.cn/file/NNB8bGwO7o6kKkxduMhcmF2Enxd)



# 飞书OKR 05 月更新

## 💾 产品名称与 OKR 名称支持自定义

OKR 支持设置产品名称、目标名称及 O 与 KR 的名称，以满足组织多样化的管理需要。设置完成后，文字效果将在用户界面的对应位置体现。

## **⏲️ 支持设置多周期**

OKR 的多周期功能支持企业管理员按照人员范围设置不同的 OKR 周期，以满足不同规模、跨度的业务需求。

**注**：本功能适用于普通周期（如月度、季度），暂不支持按照部门设置年度 OKR 。

![图片展示了飞书OKR设置中新建周期的界面。周期长度为3个月，每年第一个周期为1月 - 3月，新周期出现时间是上个周期结束前15天。OKR阶段设置中，截止于周期开始后1周，周期结束前15天。右上角有编辑、取消和确定按钮。该图片与上文提到的明细表格支持批量复制粘贴功能相关，用于说明在OKR设置中新建周期的操作界面。](https://feishu.cn/file/SChyb2ne0olMJ7xLBsYcpieInNf)
