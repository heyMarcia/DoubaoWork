# 飞书开放平台 08 月更新

## 🎈 **多维表格开放能力上新**

[多维表格开放能力简介](https://open.feishu.cn/document/uAjLw4CM/uYjL24iN/base-extensions/base-extension-introduction) 是多维表格新推出的一套开放能力，便于将多维表格中的数据与业务系统紧密结合，开发出更贴合业务场景的多维表格。你可以选择一种或多种开放形式来搭建你的插件应用：

1. **记录视图**：基于单条数据构建复杂界面。如“打印排版”插件，将记录中的不同字段排版为一篇云文档并打印。
2. **数据表视图**：基于整张数据表新增自定义视图。如“地图视图”插件，将表格中所有的地理位置在地图中展示出来。
3. **自动化操作**：基于数据/时间触发器实现自定义功能操作。如“OCR 识别插件”，当表格数据有新增时，自动识别图片中关键字段信息并回填到表格中。



## 🤖 小程序 v6.11 更新

飞书小程序基础库版本更新，从 1.0.99 （对应客户端 V6.10 版本）升级至 1.10.0（对应客户端 V6.11 版本）。请使用了 [getSystemInfo](https://open.feishu.cn/document/uYjL24iN/uQjNx4CN2EjL0YTM) 、[getSystemInfoSync](https://open.feishu.cn/document/uYjL24iN/uUjNx4SN2EjL1YTM) API，并对 SDK 版本号进行逻辑判断的开发者关注，判断这一变更是否会对业务造成影响。

具体变更表现为：在客户端 V6.11 版本中，getSystemInfo、getSystemInfo API 将返回：`{“SDKVersion”: “1.10.0”}`
