# 导演组：用**飞书文档**开选题会，实时沉淀一切沟通细节

《一年一度喜剧大赛》是深受大众喜爱的原创新喜剧竞演综艺，豆瓣评分 8.5 分。题好文一半，产出优质节目最重要的环节就是想出有趣的选题。

### 痛点

米未此前的选题方式是线下脑暴，一桌子人围在一起讨论，一个人负责用电脑记录，非常容易遗漏，但好处是互相之间可以现场传递情绪。但由于疫情，米未开始越来越多的居家远程办公，如何保持这种情绪连接？

# 节目组：用**多维表格串联演员**招募流程，一表串所有

《一年一度喜剧大赛》第二季节目筹办期间，节目组大范围地招募演员和编剧。一季节目收到的报名信息多达 5000 份，节目组需要对这些信息进行整理，安排面试、复试，组织评委打分、汇总排名，最终确定参演人员。

### 痛点：

- 整个流程使用多个工具，需要来回切换，体验差、操作繁琐；
- 面试报名环节：候选人往往通过百度云盘上传作品，节目组需要下载下来才能查看；
- 面试排名环节：每天评委在自己的表格中打分后，需要专人将打分表汇总到 Excel 表格中，花费时间进行分数排名；
- 面试评价环节：面试记录散落在面试当天的石墨文档评分表中，后续无法通过搜索直接找到某个候选人，归纳也非常困难。

### 飞书解决方案

# 艺人经纪组：用多维表格管理艺人商务，避免客户资源流失

艺人经纪组主要负责艺人的商业化产品销售，积累核心客户资源，深化艺人的商业价值；对外进行客户商业沟通谈判，对内进行跨部门项目上线。

### 痛点

- 未建立完善的客户资源库，如果销售离职会造成客户资源流失； 
- 销售 leader 无法及时了解销售进展，每周周会需要花时间和每个人单独过各自的 Excel 跟进表；
- 销售经常前期无共识，撞单情况时有发生。

### 飞书解决方案
