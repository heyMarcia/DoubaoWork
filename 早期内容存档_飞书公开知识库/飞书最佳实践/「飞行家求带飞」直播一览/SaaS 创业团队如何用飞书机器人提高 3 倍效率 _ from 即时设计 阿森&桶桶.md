## 即时设计

一直以来大家熟悉的设计工具，如 PS、AI、Sketch 等等，都是国外的。

其实我们国内也有自己的设计工具，比如「即时设计」——国内首款专业级 UI 设计工具。

即时设计的产品功能目前主要围绕 UI 设计师的需求和场景，经过一年多的发展，已快速累积了超百万的用户，其中大多数都是 UI 设计师、产品经理、开发者等互联网从业人员。

在 UI 设计方面，与 PS 这样的设计工具相比，即时设计具备以下更明显的优势：

- 个人用户永久免费
