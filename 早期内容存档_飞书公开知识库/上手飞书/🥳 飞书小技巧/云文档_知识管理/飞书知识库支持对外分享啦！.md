# **🌟 使用场景** 

💼 商务销售可搭建**产品说明书** ，将产品标准、服务内容等详细说明分享给产品使用者

💻 技术专家可搭建**开发者手册**，将工具说明、接口文档等内容提供给第三方开发者

📈 市场品牌可搭建**行业分享**，分享企业总结的经验性质文档，增加公司的行业影响力

👩🏻‍🎓 个人可搭建**个人blog**，分享你的知识、经验和见解，使用强大的飞书文档编辑器、飞书多维表格丰富能力



快来搭建你的飞书知识库吧！

# **🌟** 使用指南

如果你是知识库管理员，在已有知识库或新建的知识库中，点击「分享空间」按钮，即可配置「将空间发布到互联网」
