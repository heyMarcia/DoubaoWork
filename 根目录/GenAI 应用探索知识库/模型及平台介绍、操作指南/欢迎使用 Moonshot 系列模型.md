# 简介

![图片展示的是月之暗面（Moonshot AI）的标志。左侧为一个圆形图标，内部有黑白相间的条纹图案，右侧隐约可见“Moonshot AI”字样。该图片位于介绍月之暗面公司简介的文本旁，作为公司的标志性视觉元素，直观呈现了品牌标识，与上下文对月之暗面公司创立时间、团队背景、产品发布等介绍内容相呼应，帮助读者更直观地认识该品牌。](https://feishu.cn/file/QpM2b1KskoXaGSxzB1QcwwXQnRe)

[**月之暗面（Moonshot AI）**](https://www.moonshot.cn/)创立于 2023 年 3 月，致力于寻求将能源转化为智能的最优解，通过产品与用户共创智能。创始团队核心成员参与了 Google Gemini、Google Bard、盘古NLP、悟道等多个大模型的研发，多项核心技术被Google Gemini、Meta LLaMa、Stable Diffusion等主流产品采用。2023年10月，月之暗面推出首个支持输入20万汉字的对话式AI产品——Kimi智能助手，并在半年内升级到200万字无损上下文。2023年11月发布开放平台，将 Kimi 智能助手背后的同款大模型 API 开放给开发者和企业使用。
