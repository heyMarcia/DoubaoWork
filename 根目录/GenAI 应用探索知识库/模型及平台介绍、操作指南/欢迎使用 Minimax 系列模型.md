# 简介

![图片展示的是MiniMax的标志。标志由形似声波的线条构成，线条颜色从粉色渐变至橙色，背景为黑色。该标志置于介绍MiniMax公司的文档中“简介”部分起始处，与上下文介绍MiniMax成立时间、公司定位、研发的不同模态通用大模型以及推出的原生应用和开放平台等内容相呼应，是公司形象的直观呈现。](https://feishu.cn/file/DYGgbP1XyoiVEWx9Gj9cOIN6njb)

[**MiniMax**](https://www.minimaxi.com/) 成立于 2021 年 12 月，是领先的通用人工智能科技公司，致力于与用户共创智能。MiniMax 自主研发了不同模态的通用大模型，其中包括万亿参数的 MoE 文本大模型、语音大模型以及图像大模型。

基于不同模态的通用大模型，MiniMax 推出生产力工具海螺AI、沉浸式AI内容社区星野等原生应用。MiniMax 开放平台为企业和开发者提供安全、灵活、可靠的 API 服务，助力快速搭建 AI 应用。
